1Streaming text (token by token)SSE · TEXT_MESSAGE_CONTENT
Theory: LLM tokens arrive over 2–10s. Render each as it lands so perceived latency drops and the user sees the agent thinking. React batches the appends; a blinking cursor signals "still streaming."

2Tool call rendering (3-phase lifecycle)TOOL_CALL_START / END
Theory: each tool call goes requested → running (spinner) → result (collapsed). Exposing what the agent does builds trust. Keyed by id so concurrent calls don't collide. Commit tools get prominent treatment.
3Structured output (typed proposal, not prose)schema-constrained
Theory: the LLM returns a typed object (Pydantic/JSON schema), not free text. The UI renders per field deterministically; the rules engine can validate it. No regex parsing, no hallucinated format.
